Арифметика блока

Когда разработчик указывает только часть свойств блока, браузер рассчитывает остальные самостоятельно. В этом уроке расскажем, как он это делает.

Рассмотрим два блока — inner, вложенный в outer:

.outer {
  width: 666px;
  padding: 10px 0px;
  background-color: #1A1B22;
}

.inner {
  width: 500px; 
  margin-left: auto;
  background-color: #1162FB; 
}

Когда браузер видит описание только левого поля, он считает, что противоположное поле равно нулю:

Далее он рассчитывает размер левого поля. Браузер использует равенство, в котором слева будут свойства внутреннего блока, а справа — внешнего:

width + margin-left + margin-right + border + padding = width;

500 + 0 + margin-left + 0 + 0 = 666;

margin-left = 166.

Правила вычисления

Ту же формулу браузер использует в других случаях, когда ему не хватает описания свойств. Но для разных свойств правила разные.

margin-left + margin-right + width = width (содержащего блока) - border - padding;

Не задано одно из значений

  • если нет margin-left, он приравнивается к 0, а margin-right вычисляется;
  • если нет margin-right, он вычисляется;
  • если нет width, она вычисляется.

Не задано два значения

  • если нет margin-left и margin-right, но есть width, то margin-left приравнивается к 0, а margin-right вычисляется;
  • если нет margin-left и width, то margin-left приравнивается к 0, width вычисляется;
  • если нет margin-right и width, то margin-right приравнивается к 0, width вычисляется;

margin+ width = width (содержащего блока) - border - padding

Что-то с auto и width

  • если margin-left содержит auto, то margin-right имеет значение 0, margin-left вычисляется;
  • если margin-right содержит auto, то margin-left имеет значение 0, margin-right вычисляется;
  • если каждый содержит значение auto, расчётное пространство распределяется равномерно.

Что-то с auto и без width

  • если любой из margin имеет значение auto, то оба этих margin получают значение 0, а width вычисляется.

Заданы оба margin и width

  • пересчитывается margin-right.

Не заданы ни margin, ни width

  • margin-left = margin-right = 0, width будет вычисляться.

Примеры

Разберём несколько частных случаев.

Первый пример:

.outer {
  width: 666px;
  padding: 10px 0px;
  background-color: #1A1B22;
}

.inner {
  margin-left: 100px;
  margin-right: 300px;
  width: 300px; 
  background-color: #1162FB;
}

Ширина внутреннего блока превышает размер внешнего. Чтобы всё поместилось, браузер пересчитает правое поле. Вычисления происходят по той же формуле:

width + margin-left + margin-right + border + padding = width;

300 + 100 + margin-right + 0 + 0 = 666;

margin-right = 266.

Второй пример:

.outer {
  width: 666px;
  padding: 10px 0px;
  background-color: #1A1B22;
}

.inner {
  margin: 0 auto;
  width: 300px; 
  background-color: #1162FB;
}

Поля внутреннего блока нужно рассчитать. Но из свойств следует, что они равны друг другу:

width + margin-left + margin-right + border + padding = width;

300 + margin-left + margin-right + 0 + 0 = 666;

margin-left + margin-right = 366;

margin-left = 183;

margin-right = 183.

Третий пример:

.outer {
  width: 666px;
  padding: 10px 0px;
  background-color: #1A1B22;
}

.inner {
  margin-right: auto;
  width: 300px; 
  background-color: #1162FB;
}

Левое поле не задано и приравнивается к нулю. Правое рассчитывается:

width + margin-left + margin-right + border + padding = width;

300 + 0 + margin-right + 0 + 0 = 666;

margin-right = 366.

Четвёртый пример:

.outer {
  width: 666px;
  padding: 10px 0px;
  background-color: #1A1B22;
}

.inner {
  margin-left: auto;
  width: 300px; 
  background-color: #1162FB;
}

Здесь, наоборот, правое поле не задано и приравнивается к нулю. А левое поле рассчитывается:

width + margin-left + margin-right + border + padding = width;

300 + 0 + margin-left + 0 + 0 = 666;

margin-left = 366.

Пятый пример:

.outer {
  width: 666px;
  padding: 10px 0px;
  background-color: #1A1B22;
}

.inner {
	margin-left: 100px; 
  background-color: #1162FB;
}

Задано левое поле, а правое приравнивается к нулю. Остаётся вычислить width:

width + margin-left + margin-right + border + padding = width ;

width + 100 + 0 + 0 + 0 = 666;

width = 566.

Шестой пример:

.outer {
  width: 666px;
  padding: 10px 0px;
  background-color: #1A1B22;
}

.inner {
  margin-left: 100px; 
  margin-right: 200px;
  background-color: #1162FB;
}

Когда заданы оба поля, width вычисляется точно так же:

width + margin-left + margin-right + border + padding = width ;

width + 100 + 200 + 0 + 0 = 666;

width = 366.

Размеры в процентах

Высота блока может быть задана в процентах, только у родительского блока высота должна быть указана явно:

.outer {
  width: 500px;
  height: 100px;
  background-color: #1A1B22;

}

.inner {
  height: 50%;
  width: 70%;
  background-color: #1162FB;
}

В противном случае свойство height будет проигнорировано:

.outer {
  width: 500px;
  /* height: 100px;  */
	background-color: #1A1B22;

}

.inner {
  height: 50%;
  width: 70%;
  background-color: #1162FB;
}

Иначе обстоит дело со свойством width. Здесь явное указание ширины у родителя уже не обязательно:

.outer {
  /* width: 500px; */
  height: 100px;
	background-color: #1A1B22;
  padding: 10px 0px;
}

.inner {
  height: 50%;
  width: 70%;
  background-color: #1162FB;
}
