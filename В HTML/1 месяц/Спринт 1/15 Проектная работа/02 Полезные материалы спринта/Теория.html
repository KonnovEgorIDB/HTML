    Одни из самых полезных расширений для WebStrorm:

    • FTP/SFTP Connectivity — поможет настроить удалённую работу по SFTP или SSH,

    В самом маркетплейсе вы также найдёте плагины для работы с PostCSS, NodeJS, Swagger, для настройки прогресс-бара в виде Nyan Cat или добавления интеграции с Docker (и Kubernetes в том числе) либо TeamCity.

  • VS Code.

    Расширения для VS Code, которые упростят работу над проектами этого курса:

    • GitLens — интегрирует Git в ваш код;
    • Live Share — транслирует код вашим коллегам;
    • REST Client — проверяет запросы прямо в IDE;
    • Template Generator — генерирует сниппеты кода;
    • Import Cost — показывает размеры пакетов или файлов.

    Существуют и другие, не менее полезные. Например:

    • JavaScript and TypeScript,
