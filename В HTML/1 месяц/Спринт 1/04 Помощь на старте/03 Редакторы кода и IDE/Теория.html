Редакторы кода и IDE

Без чего невозможно покорить вершину? Правильно, без снаряжения. Не просто какого-то, а правильно подобранного. Надёжного, которое не подведет в самый сложный момент. А какое снаряжение у фронтендера? В первую очередь то, где он пишет код.

Уверены, что ранее код вы уже писали. Кто-то делал это в IDE (от англ. Integrated Development Environment, «интегрированная среда разработки»), а кому-то ближе любимый редактор. Это дело вкуса. Вне зависимости от того, в чём вы работали ранее, советуем попробовать разные варианты, чтобы выбрать именно тот, что подходит вам. Определимся с терминологией:

  • IDE обещает закрыть все потребности разработчика: от автодополнения и навигации по коду до тестирования и контроля версий. Они подходят для разработки больших проектов и рефакторинга.
  • Редактор кода — текстовый редактор с базовыми функциями для разработки: подсветкой синтаксиса, автодополнением. Редакторы кода умеют меньше IDE, но их возможности увеличиваются через установку расширений. Простейшие консольные редакторы, такие как Vim, могут приблизиться к IDE по количеству и качеству функционала, если потратить время на настройку.

Если раньше не пробовали, обратите внимание на IDE WebStorm и редактор кода VS Code.

VS Code — лёгкий, быстрый и бесплатный редактор. Из коробки доступны только базовые функции, но есть расширения под разные языки программирования и задачи. VS Code написан на JavaScript — вы увидите, что некоторые навыки из этого курса пригодятся для настройки или доработки его расширений.

Расширения для VS Code, которые упростят работу над проектами этого курса:

  • GitLens — интегрирует Git в ваш код;
  • Live Share — транслирует код вашим коллегам;
  • REST Client — проверяет запросы прямо в IDE;
  • Template Generator — генерирует сниппеты кода;
  • Import Cost — показывает размеры пакетов или файлов.

Существуют и другие, не менее полезные. Например:

  • JavaScript and TypeScript,
  • SFTP.

Ещё больше плагинов с красивыми темами и утилитами можно найти на маркетплейсе.

WebStorm — IDE для JavaScript, TypeScript и популярных фреймворков. Большинство функций, которые VS Code получает от расширений, в WebStorm работают «из коробки». И часто работают лучше. Настройка IDE займёт меньше времени, чем настройка VS Code.

Есть и минусы. IDE требует более мощного компьютера и работает медленнее. Чтобы пользоваться WebStorm больше месяца, придётся оформить подписку. Для студентов и разработчиков проектов с открытым кодом подписка останется бесплатной.

Если некоторые функции WebStorm окажутся полезными, но в остальном VS Code понравился больше, — поищите расширения, которые добавят в VS Code те же возможности.

Одни из самых полезных расширений для WebStrorm:

  • Material Theme UI — поможет сделать вашу IDE краше всех,
  • инструменты для работы с шаблонизаторами: Handlebars или Pug,
  • FTP/SFTP Connectivity — поможет настроить удалённую работу по SFTP или SSH,
  • Quokka — позволит быстро проверить небольшие куски кода.

В самом маркетплейсе вы также найдёте плагины для работы с PostCSS, NodeJS, Swagger, для настройки прогресс-бара в виде Nyan Cat или добавления интеграции с Docker (и Kubernetes в том числе) либо TeamCity.

Полезный совет: если начинаете работать с новой технологией (например, с Docker), загляните на маркетплейс своего редактора или IDE. Есть шанс, что там найдётся расширение, которое сделает разработку удобнее.
