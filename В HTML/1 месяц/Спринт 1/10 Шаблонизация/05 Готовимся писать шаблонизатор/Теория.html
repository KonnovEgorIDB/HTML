Готовимся писать шаблонизатор

Шаблонизатор — это не страшно. Чтоб это понять, давайте сами реализуем аналог всего в нескольких JS-файлах. Потом, применив написанный вами шаблонизатор, отрисуем блок с текстом, на который можно делать клик мышкой.

Шаблонизатор из урока будет уметь работать с:

  • примитивами,
  • объектами,
  • функциями.

Выбираем шаблон

Чтобы начать с простого, сделаем шаблоном обычную JS-строку.

Создадим файл block.tmpl.js. Почему *.tmpl.js? Потому что такие файлы проще отличить от обычных JS-файлов. .tmpl — это просто дополнение к названию файла, а не его расширение. Расширением всё так же остаётся последняя часть — .js.

// block.tmpl.js

window.blockTemplate = (function() {
  return `
<!-- Можно {{}} с пробелами, можно без-->
<div class="{{ className }}">
	<span onClick="{{ handleClick }}">{{text}}</span>
	<span>{{ user.info.firstName }}</span>
</div>
`;
})();

Шаблон — это обычная JavaScript строка, которая возвращается из IIFE-модуля.

В данной строке будем использовать шаблонные переменные, обёрнутые в jinja-формат {{ content }}. Какой формат удобнее вам — решайте сами, вариаций очень много.

Почему не { content }? Потому что можно легко спутать с синтаксисом языка или, например, с объектами, шаблонными строками, интерфейсами. Вероятность встретить {{ }} гораздо ниже. Советуем как обёртку шаблонного значения использовать то, что сложно перепутать с чем-то ещё.

Подготовим утилиту обработки объектов

Сделаем утилиту get, которая будет обращаться к объектам следующим способом:

const obj = {
	data: {
		first: 'Vladislav',
		second: true,
	},
};

get(obj, 'data.first'); // 'Vladislav'
get(obj, 'data.third'); // undefined
get(obj, 'data.third', 'defaultValue'); // 'defaultValue'

Зачем нужна эта функция? В строке-шаблоне используется получение данных из объекта <span>{{ user.info.firstName }}</span>. Чтобы не поймать ошибку вида Cannot read property 'info' of undefined, было бы здорово уметь получать свойства подобным образом.

Что нужно для реализации такой функции?

Для получения свойств data.first используется dot-нотация (через точку). Как можно получать данные у объекта, зная поле в константе?

const field = 'data';
const obj = {
	data: {
		first: 'Vladislav',
		second: true
	}
};

console.log(obj[field]); // {first: 'Vladislav', second: true}, то есть содержимое data

А как можно пройтись по всем ключам, которые написаны через точку?

const keys = 'a.b.c'.split('.'); // ['a', 'b', 'c']
keys.reduce((result, key) => `${result}-${key}`, ''); // '-a-b-c'

Соединим знания выше в одну функцию:

function get(obj, path) {
	const keys = path.split('.');
	return keys.reduce((result, key) => result[key], obj);
};

Протестируем, как она работает:

const obj = {
	user: {
		isPoet: true,
		info: {
		  firstName: 'Alexander',
		  lastName: 'Pushkin'
		},
	},
};

get(obj, 'user.isPoet'); // true
get(obj, 'user.info.firstName'); // Alexander
get(obj, 'user.info.contacts'); // undefined
get(obj, 'user.info.contacts.email'); // Uncaught TypeError: Cannot read property 'email' of undefined

Если пытаемся получить что-то от undefined, как в последнем примере, — упадём с ошибкой. Не хотелось бы, а значит, добавим в функцию обработку этого случая:

function get(obj, path) {
	const keys = path.split('.');

	let result = obj;
	for (let key of keys) {
	  const value = result[key];

	  if (!value) {
		return undefined;		
	  }

	  result = value;
	}

	return result;
};

Проверим, что изменилось:

const obj = {
	user: {
		isPoet: true,
		info: {
			firstName: 'Alexander',
			lastName: 'Pushkin'
		},
	},
};

get(obj, 'user.isPoet'); // true
get(obj, 'user.info.firstName'); // Alexander
get(obj, 'user.info.contacts'); // undefined
get(obj, 'user.info.contacts.email'); // undefined

Теперь всё в порядке. У пользователя не будет белого экрана от ошибки получения свойства у объекта.

Но хочется ещё пробрасывать значение по умолчанию, если желаемый ключ не найден. Когда это может быть нужно? Например, мы ждём, что значением ключа будет Boolean. В таком случае — можем вернуть false по умолчанию.

function get(obj, path, defaultValue) {
	const keys = path.split('.');

	let result = obj;
	for (let key of keys) {
		result = result[key];

		if (result === undefined) {
			return defaultValue;		
		}
	}

	return result ?? defaultValue; // "??" — [оператор нулевого слияния](https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Operators/Nullish_coalescing_operator) (не поддерживается старыми браузерами, для них нужен полифилл)
}

Посмотрим на результат:

const obj = {
	user: {
		isAdmin: false,
		isPoet: true,
		info: {
		  firstName: 'Alexander',
		  lastName: 'Pushkin'
		}
	}
};

get(obj, 'user.isPoet'); // true
get(obj, 'user.info.firstName'); // Alexander
get(obj, 'user.info.contacts'); // undefined
get(obj, 'user.info.contacts.email'); // undefined
get(obj, 'user.info.contacts.email', 'a.pushkin@ya.ru'); // 'a.pushkin@ya.ru'
get(obj, 'user.isAdmin', true); // false

Ура! Теперь мы можем работать с объектами. В следующем уроке начнём писать сам шаблонизатор.
