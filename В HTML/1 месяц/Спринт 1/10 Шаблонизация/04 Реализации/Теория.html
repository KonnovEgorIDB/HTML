pug

Getting Started

Популярность

Количество «звёздочек», «форков» и использований говорит само за себя.

Пример шаблона

Рассмотрим пример, где используются все части MVP, которые будут вам нужны:

table
thead
    tr
        th #ID
        th Description
        th Actions
tbody
    each item, i in itemlist
        tr
            th(scope='row') #{item.id}
            td #{item.description}
            td
                button(onclick="editItem(#{item.id})", title="Edit")

Создали таблицу из трёх колонок и нескольких строк. Строки генерируются в цикле, в третьей колонке на каждой строке есть кнопка с действием. Кнопка будет вызвана с id строки.

Пример работы с шаблоном:

import pug from 'pug';

const compilationFunc = pug.render(tmpl); // tmpl — это шаблон таблицы из кода выше
console.log(compilationFunc({itemList: [], ...})); // Получим на выходе HTML
																									 // Можно получать на выходе не сразу HTML, а функцию с управлением DOM-деревом

Документация

В ней много примеров, но есть далеко не всё или их сложно найти.

Поддержка

Активно развивается и поддерживается до сих пор.

Субъективное мнение

Несмотря на всю мощь и большой функционал теряется самое главное — читаемость и «наглядность».

Понятно, что привыкнуть можно ко всему и читать Pug тоже. Однако мы хотим использовать шаблонизаторы отчасти потому, что привыкли читать разметку в HTML.

Получается, что мы уходили от плохой читаемости нативного DOM API и пришли к не самой привычной читаемости pug-шаблонов.

Handlebars

Handlebars

Не менее популярный и широко используемый инструмент.

Пример шаблона:

<div class="comments">
  {{#each comments}}
    <div class="comment">
      <h2>{{subject}}</h2>
      {{{body}}}
    </div>
  {{/each}}
</div>

Создали список комментариев с информацией об отправителе и непосредственно текстом.

Пример работы с шаблоном:

Handlebars.registerHelper('each', function(context, options) {
  let ret = '';

  for (let i = 0, j = context.length; i < j; i++) {
    ret = `${ret}${options.fn(context[i])}`;
  }

  return ret;
});

Документация

Документация о функционале местами богаче, чем у Pug, но несильно. Всё так же поисковик + исходники вам в помощь.

Поддержка

Поддержки меньше, но она есть, а функционала хватает, чтобы сделать всё необходимое.

Субъективное мнение

Местами не самые удобные способы работы с функциями не смогут затмить наглядность шаблона.

Но и назвать весь функционал неудобным нельзя, поскольку он охватывает почти всё, что нужно. MVP функционал покрыт на 150% и даже больше, но могут быть трудности при реализации сложных интерфейсов.

lodash.template

Один из инструментов внутри Lodash — это функция template. Этот инструмент позволяет работать с функцией как с полноценным шаблонизатором.

Lodash Documentation

Популярность

Lodash очень популярная библиотека, которую часто используют в проектах как полностью, так и отдельные её части.

Пример шаблона:

<!-- подключем библиотеку из CDN -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/lodash.js/4.17.15/lodash.js"></script>

<script type="text/template" id="chat-template">
		<ul class="chats">
		  <% for (var i = 1; i <= count; i++) { %>
				  <li class="chat"><%=i%></li>
		  <% } %>
		</ul>
</script>

<script>
  const tmpl = _.template(document.getElementById('chat-template').innerHTML);

  const result = tmpl({count: 5});
  document.write(result);
</script>

const compiled = _.template('<% _.forEach(users, function(user) { %><li><%- user %></li><% }); %>');
compiled({'users': ['fred', 'barney']});
// => '<li>fred</li><li>barney</li>'

Документация

Документация Lodash — это описание сигнатуры функции, зачем она нужна, и множество примеров использования. Остальное находится опытным путём, поиском и чтением исходников.

Поддержка

Активно поддерживается как разработчиками, так и как open-source проект.

Субъективное мнение

Данный инструмент — скорее полезная функция, нежели полноценный шаблонизатор, хотя все задатки для шаблонизатора есть.

С помощью этой функции можно написать свой класс для работы с шаблонизацией.

JSX

Не просто шаблонизатор, а полноценная система, которая также:

  • замещает много кода по типу React.createElement, document.createElement,
  • делает шаблоны простыми, лёгкими, удобными.

В обычных проектах, вне контекста данных библиотек и фреймворков, использовать JSX нет смысла. Подробнее о нём расскажем в следующем модуле, где будет использоваться React.

Итого

Реализаций шаблонизаторов много. Можно написать свой для получения огромного дополнительного опыта, можно взять готовый. Но самое главное — понимать, что внутри никакая не магия, а обычный, знакомый, а главное мощный JavaScript.
