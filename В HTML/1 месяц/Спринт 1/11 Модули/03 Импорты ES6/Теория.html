Импорты ES6

В стандарте ES6 появились специальные директивы:

  • export помечает, какие фрагменты кода должны быть доступны вне модуля;
  • import подключает части модуля, размеченные через export.

Выполним импорт из файла file2.js в file1.js:

  • file2.js

    function log(obj) {
  console.log("log", obj);
}


export const data = { a: 1 };


function first() {
  console.log("first");
}
export function second() {
  first();
  console.log("second");
}


export default log;

  • file1.js

    import otherNameForLogger, { data as obj, second } from "./file2";


// data уже не определён в данной области видимости — его переназвали с помощью as
otherNameForLogger(obj); // log {a: 1}
second(); // first
		  // second

Мы использовали разные способы импорта и экспорта:

  • При импорте функция log получила другое название: import otherNameForLogger, ... from "./file1". Это возможно в случае экспорта по умолчанию — когда функция, переменная или класс были экспортированы с помощью export default.
  • Для объекта data использован «именованный» экспорт. Здесь действует директива export.

Данный вид модулей — очень мощный инструмент в JavaScript, который позволяет писать изолированные и атомарные модули.

Рассмотрим пример с несколькими файлами:

  • consts.js

    export const chat = {id: 1, title: 'chat_1'};

  • invert.js

    import {chat} from './consts';


function invert() {
		// ... реализация invert
}


invert(chat); // {1: 'id', chat_1: 'title'}


export default invert;

  • index.js

    import invert from './invert';
import {chat as obj} from './consts';


invert(obj); // {1: 'id', chat_1: 'title'}

И в invert.js, и в index.js объект chat имеет одни и те же свойства. То есть модуль можно импортировать одновременно как в основную программу, так и в другие модули.

Браузеры

В браузерах модули подключаются также через тег script, но с типом подключения — module.

<script src="file.js" type="module"></script>

Особенности модулей ES2015+

  • В модулях всегда действует режим use strict;
  • У каждого модуля своя изолированная область видимости;
  • Код в модуле выполняется один раз за один импорт;
  • В модулях нельзя обратиться к глобальному объекту, в том числе через this:
<script>
  console.log(this); // window
</script>

<script type="module">
  console.log(this); // undefined
</script>
