CSS через JS

Основная идея управления CSS через JS — представление стилей через объект. Стили записываются в тег style, а при необходимости создаются дополнительные классы.

У такого подхода есть ряд преимуществ:

  • JS более гибкий и позволяет делать всё, что захотите;
  • можно задавать различные темы и стили страницы в runtime;
  • уменьшение размера загружаемых стилей и ускорение первого рендера;
  • нет кеша.

Но есть и минусы:

  • сложнее покрывать автотестами систему без классов и адекватных имён;
  • управлять стилями гораздо сложнее, чем классами в долгосрочной перспективе.

Реализаций подобных механизмов много. Один из примеров — JSS.

Подобные библиотеки позволяют описывать и использовать стили прямо из JavaScript:

const styles = {
  '@global': {
    body: {
      color: 'green'
    },
    a: {
      textDecoration: 'underline'
    }
  },
  button: {
    fontSize: 12,
    '&:hover': {
      background: 'blue'
    }
  },
  ctaButton: {
    extend: 'button',
    '&:hover': {
      background: color('blue')
        .darken(0.3)
        .hex()
    }
  },
  '@media (min-width: 1024px)': {
    button: {
      width: 200
    }
  }
}

const {classes} = jss.createStyleSheet(styles).attach()

document.body.innerHTML = `
  <button class="${classes.button}">Button</button>
  <button class="${classes.ctaButton}">CTA Button</button>
`

В первой половине курса использовать такие библиотеки запрещено. Необходимый минимум их функций вы реализуете самостоятельно.

Еще одно популярное решение — styled components. Используется вместе с React.

Обратимся к примеру из документации:

const Button = styled.button`
  background: transparent;
  border-radius: 3px;
  border: 2px solid palevioletred;
  color: palevioletred;
  margin: 0.5em 1em;
  padding: 0.25em 1em;

  ${props => props.primary && css`
    background: palevioletred;
    color: white;
  `}
`;

const Container = styled.div`
  text-align: center;
`

render(
  <Container>
    <Button>Normal Button</Button>
    <Button primary>Primary Button</Button>
  </Container>
);
