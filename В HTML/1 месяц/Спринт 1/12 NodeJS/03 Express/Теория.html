Express

В качестве веб-сервера, который будет раздавать клиентам index.html, мы возьмём сочетание NodeJS + пакет Express.

Express — это инструмент, который позволяет написать веб-сервер любой сложности. Даже некоторые высоконагруженные приложения работают, используя NodeJS и Express.

После того как клонировали свой репозиторий и сделали init, необходимо установить пакет. И установить его так, чтобы он правильно сохранился в зависимостях проекта.

Если сделать npm install express, то npm по умолчанию сохранит его в package.json и запишет в dependencies. Если вам нужен Express только при разработке, но не в продакшн версии продукта, его необходимо сохранить в devDependencies:

$ npm install express --save-dev # Можно для сокращения npm i express --save-dev

Можно начинать его использовать. Наша задача сделать так, чтобы мы смогли открыть браузер на странице http://localhost:4000/ и увидеть белую страницу с надписью Hello, my comrade!.

Создадим простой файл в корне репозитория index.html :

<!DOCTYPE html>
<html lang="en">
<head>
  <title>Hello</title>
  <meta charset="utf-8">
</head>
<body>
	<div>Hello, my comrad!</div>
</body>
</html>

Теперь напишем код на NodeJS, который запустит сервер и будет отдавать этот HTML по запросу на localhost.

// server.js
const express = require('express');

const app = express();
const PORT = 4000;

app.use(express.static('./'));

app.listen(PORT, function () {
  console.log(`Example app listening on port ${PORT}!`);
});

Чтобы запустить программу, вызовите скрипт:

$ node ./server.js

Заметим, что, запустив свой сервер, вы можете получить HTML не только в браузере, но и в терминале, используя команду curl http://localhost:4000/, или в Postman, Owasp ZAP и иных подобных инструментах.

Структура проекта на данном шаге будет следующая (не учитывая node_modules после установки зависимостей):

.
├── index.html
├── package-lock.json
├── package.json
└── server.js

Отправляем HTTP-запросы

Повторим: отправлять HTTP-запросы можно как утилитой cURL, так и браузером, а также специальными утилитами, например Postman.

cURL — инструмент несложный. Ознакомиться с ним подробнее вы можете в следующих источниках:

  • cURL;
  • Как использовать cURL;
  • Что JavaScript-разработчику следует знать о cURL.

Кроме быстрой отправки запроса, cURL удобен ещё и тем, что он уже установлен в bash-подобных оболочках. Лишних действий не нужно, но для отправки запросов используют и альтернативные решения, например HTTPie.

Postman — более гибкий и мощный. Это не просто CLI утилита — это полноценное приложение. Оно умеет не только отправлять запросы различной сложности, но и генерировать код, автоматизировать тестирование API, публиковать запросы или группы запросов между командами.
