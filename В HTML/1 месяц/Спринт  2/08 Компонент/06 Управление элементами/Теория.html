Управление элементами

Иногда нужно обратиться к вложенному компоненту или просто уметь обращаться к элементу прямиком в DOM’е. Например, вы работает с картами, в реализации которых очень многое завязано на работу с DOM’ом (например, Яндекс.Карты или Google Maps).

Для этого вы можете просто навешивать ID всем или только необходимым элементам. Чтобы это сделать правильно, воспользуйтесь свойством инкапсуляции логики. ID будет создаваться внутри Block (внутри не самого компонента, а его класса родителя). Соответственно вся логика с ID будет внутри.

Для этого добавим создание уникального ID компонента. В этом нам поможет алгоритм генерации UUID v4. Вы можете использовать пакет uuid из npm. Если интересно как именно происходит генерация UUID, на эту тему есть подробная статья на Хабре.

Пример использования:

import {v4 as makeUUID} from 'uuid';

const uuid = makeUUID(); // '23a91df9-2a89-4357-b297-ec2924d854e3'

Вот такие «метки» можно вешать на внешние теги ваших компонентов. Чтобы не делать лишнюю работу, их можно добавлять только на необходимые для вас блоки. То есть триггерить создание с ID можно вот так:

class MyOtherBlock extends Block {
  constructor(props) {
    super("section", props);
  }

  render() {
    const { text } = this.props;

    const source = "<div>{{text}}</div>";
    const template = Handlebars.compile(source);

    return template({ text });
  }
}

const button = new MyOtherBlock({
  text: "Some text",
  settings: {withInternalID: true},
});

В DOM это будет выглядеть так:

<section data-block-id='23a91df9-2a89-4357-b297-ec2924d854e3'>
  <div>Some text</div>
</section>

Но сам по себе UUID в DOM не попадёт, а значит нужно научиться его туда добавлять. Элемент у нас создаётся в классе Block. В конструкторе класса необходимо создать UUID данного компонента и добавить как атрибут DOM-элемента. Сделать это можно так:

class Block {
  static EVENTS = {
    INIT: "init",
    FLOW_CDM: "flow:component-did-mount",
	// ...
  };

  // ...
  _id = null;

  constructor(tagName = "div", props = {}) {
    const eventBus = new EventBus();
    this._meta = { /* ... */ };
		
    // Генерируем уникальный UUID V4
    this._id = makeUUID();

     // Добавляем этот ID в актуальные this.props компонента, чтобы можно было получить доступ к id везде
    this.props = this._makePropsProxy({ ...props, __id: this._id });

    // ...
  }

	_createDocumentElement(tagName) {
    const element = document.createElement(tagName);
    element.setAttribute('data-id', this._id);
    return element;
  }
}

Теперь ID можно получить даже из метода render:

class MyOtherBlock extends Block {
  constructor(props) {
    super("section", props);
  }

  render() {
    const { text, __id } = this.props;

    const source = "<div>{{text}}</div>";
    const template = Handlebars.compile(source);

	console.log(__id); // '23a91df9-2a89-4357-b297-ec2924d854e3'

    return template({ text });
  }
}

const button = new MyOtherBlock({
  text: "Some text",
	settings: {withInternalID: true},
});

Осталось добавить работу со свойством withInternalID, чтобы ID подставлялся только в нужных компонентах. Для этого необходимо добавить в конструкторе блока правильное условие и всё. Попробуйте сделать это самостоятельно.
