History API

Согласно документации, History API — интерфейс для управления историей браузера в пределах сессии. С помощью API разработчики получают доступ к истории посещённых страниц в рамках вкладки или фрейма, который загрузили внутри страницы.

Он позволяет перемещаться по истории переходов, а также управлять содержимым адресной строки браузера.

Примеры использования API:

// Перемещение вперёд и назад по истории
window.history.back(); // работает как кнопка «Назад»
window.history.forward(); // работает как кнопка «Вперёд»
 
window.history.go(-2); // перемещение на несколько записей
window.history.go( 2);
 
const length = window.history.length; // количество записей

Изменять историю можно через методы pushState (добавляет запись в историю) и replaceState (заменяет последнюю запись в истории):

// Изменение истории
const state = { foo: 'bar' };
window.history.pushState(
  state,         // объект состояния
  'Page Title',  // заголовок состояния
  '/pages/login'  // URL новой записи (относительно домена)
);
window.history.replaceState(state2, 'Other Title', '/another/page');

Если действия в браузере привели к изменению активной записи истории, объекту window будет отправлено событие popstate. Такими действиями являются, например, нажатие кнопки «Назад» или вызов history.back() из JavaScript. При этом вызов pushState() или replaceState() событие popstate не повлекут.

window.onpopstate = event => {
	console.log(location.pathname);
};
 
history.pushState({ page: 1 }, 'Title 1', '/menu?page=1');
history.pushState({ page: 2 }, 'Title 2', '/app?page=2');
history.pushState({ page: 3 }, 'Title 3', '/chats?page=3');
history.back();   // /app?page=2
history.back();   // /menu?page=1
history.go(2);    // /chats?page=3
