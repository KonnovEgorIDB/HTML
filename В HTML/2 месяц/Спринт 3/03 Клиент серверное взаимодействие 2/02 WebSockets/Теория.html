WebSockets

Протокол WebSocket («веб-сокет»), описанный в спецификации RFC 6455, обеспечивает возможность обмена данными между браузером и сервером через постоянное соединение. Данные передаются в обоих направлениях в виде «пакетов», без разрыва соединения и дополнительных HTTP-запросов.

Основная цель — обойти ограничение протокола HTTP на формат запрос-ответ, чтобы была возможность отправлять сообщения от сервера на клиент.

Подробнее об этом можно почитать в «Современном учебнике JavaScript».

Поддержка хорошая, но для старых версий браузеров есть отдельные библиотеки.

Источник: https://caniuse.com

Основные преимущества веб-сокетов:

  • возможность отправки с сервера на клиент,
  • нет оверхэда на открытие соединения, так как сообщения проходят через одно TCP-соединение,
  • хорошая поддержка браузерами,
  • очень простой API.

WebSockets часто используют для реализации:

  • онлайн (real-time) игр,
  • чатов и веб-мессенджеров,
  • push-уведомлений и других уведомлений от сервера.

Работа с веб-сокетами базируется на событиях. Здравствуй, Event Bus!

const ws = new WebSocket('ws://example.com/ws');
// если страница загружена по https://
const wss = new WebSocket('wss://example.com/ws');
 
// События WebSocket
ws.addEventListener('open', listener);     // соединение установлено
ws.addEventListener('message', listener);  // пришло новое сообщение
ws.addEventListener('error', listener);    // ошибка
ws.addEventListener('close', listener);    // сокет закрылся

Кроме строк, WebSocket умеет оперировать ещё и бинарными данными:

const buffer = new ArrayBuffer(128);
socket.send(buffer); 

const intview = new Uint32Array(buffer);
socket.send(intview);

const blob = new Blob([buffer]);
socket.send(blob);

Ниже расскажем, как правильно использовать сокеты.

Во-первых, внутри команды стоит договориться с бэкенд-разработчиками о собственном формате обмена сообщениями между клиентом и сервером. Зафиксируйте, например, во внутренних Wiki или Trello форматы всех сообщений в приложении:

{
	"action": "SEND_TEXT",
	"payload": { "message": "text" }
}
 
{
  "action": "MESSAGES",
  "payload": { "page": 2 }
}

Во-вторых, стоит написать сервис-обёртку вокруг WS, который будет отправлять и принимать сообщения. Это позволит сделать удобный интерфейс, где будет агрегирована работа с форматированием и форматом данных:

const webSocketService = new WebSocketService('/ws');
 
webSocketService.send('SEND_TEXT', { message: 'text' });
webSocketService.subscribe('MESSAGES', function (payload) {
  const state = payload.state;
  chat.setProps(state);
});
