Рубрика «Решаем вместе»: isEqual

Написать универсальное решение для глубокого сравнения произвольных значений (классы, функции, Map, Set, встроенные объекты и рекурсивные значения) — не просто. Но сравнить «JSON-валидные» объекты (далее будем называть их «простые объекты») — это частая задача (например, для методов shouldComponentUpdate в ReactJS) и иметь под рукой свой хелпер лишним не будет. Поэтому сразу проговорим ограничения — функция принимает на вход объекты, которые содержат в себе примитивы, объекты и массивы.

Напишем вспомогательные функции, которые будут определять, что значение — это объект или массив. С массивами всё просто: в JS есть встроенный метод для определения, является ли переменная массивом: Array.isArray():

function isArray(value: unknown): value is [] {
  return Array.isArray(value);
}

Ранее рассказывали, что в TypeScript есть Type Guard **— выражение, которые выполняет runtime-проверку и гарантирует указанный тип в блоке ниже. То есть в данном случае, если метод вернёт true, то TypeScript сузит тип value до массива.

Для объектов нет встроенного метода, поэтому придётся написать свой. Отфильтровать примитивы можно с помощью typeof value === 'object', но важно не забыть проверить значение на null (так как typeof null вернёт 'object'), отфильтровать функции и массивы (проверив свойство constructor у объекта, которое должно указывать на Object) и проверить, что это не встроенный объект (например, не Date):

type PlainObject<T = unknown> = {
  [k in string]: T;
};

function isPlainObject(value: unknown): value is PlainObject {
  return typeof value === 'object'
    && value !== null
    && value.constructor === Object
    && Object.prototype.toString.call(value) === '[object Object]';
}

Проверку на встроенные объекты можно сделать, вызвав toString() в контексте объекта и проверив значение на '[object Object]' (например, в случае с Date вернётся строка '[object Date]'). Не забываем про TypeScript: опишем «простой объект» типом PlainObject и используем Type Guard.

Опишем общий метод, который проверит, что значение является или массивом, или «простым объектом»:

function isArrayOrObject(value: unknown): value is ([] | PlainObject) {
  return isPlainObject(value) || isArray(value);
}

С вспомогательными методами всё, перейдём к функции isEqual. Если значения в двух объектах равны массиву или объекту, то необходимо рекурсивно проверить дочерние значения, иначе просто проверяем значения на строгое равенство.

Проитерироваться по массиву и объекту можно с помощью for of и Object.entries (для массива [1,2,3] Object.entries сформирует массив вида [['0', 1], ['1', 2], ['2', 3]]):

function isEqual(lhs: PlainObject, rhs: PlainObject) {
  for (const [key, value] of Object.entries(lhs)) {
    const rightValue = rhs[key];
    if (isArrayOrObject(value) && isArrayOrObject(rightValue)) {
			// Здесь value и rightValue может быть только массивом или объектом
			// и TypeScript это понимает с помощью Type Guard
      if (isEqual(value, rightValue)) {
        continue;
      }
      return false;
    }

    if (value !== rightValue) {
      return false;
    }
	}

  return true;
}

Также сразу стоит проверить, что у объектов или массивов одинаковое количество элементов (для объектов можно получить массив с ключами и сравнить их длину) и вернуть false (не уходя в рекурсию на сложных объектах), если количество полей не равно друг другу:

function isEqual(lhs: PlainObject, rhs: PlainObject) {
	// Сравнение количества ключей объектов и массивов
  if (Object.keys(lhs).length !== Object.keys(rhs).length) {
    return false;
  }

  for (const [key, value] of Object.entries(lhs)) {
    const rightValue = rhs[key];
    if (isArrayOrObject(value) && isArrayOrObject(rightValue)) {
			// Здесь value и rightValue может быть только массивом или объектом
			// И TypeScript это обрабатывает
      if (isEqual(value, rightValue)) {
        continue;
      }
      return false;
    }

    if (value !== rightValue) {
      return false;
    }
  }

  return true;
}

На этом всё, типизированный isEqual готов (с ограничениями, которые мы установили ранее).

Несколько интересных кейсов:

isEqual({ foo: NaN }, { foo: NaN }); // false
isEqual({ foo: () => true }, { foo: () => true }); // false
isEqual({ foo: [1, 2] }, { foo: { 0: 1, 1: 2 } }); // true
  1. NaN !== NaN, следовательно, объекты не будут равны. Чтобы функция возвращала true, можно проверить два значения на NaN с помощью Number.isNaN.
  2. Изначально мы исключили функции из сравнения, но если хотите их сравнить, можно использовать метод toString(), который вернёт строковое представление функции.
  3. Сейчас объекты и массивы сравниваются вместе, поэтому при сравнении массивоподобного объекта с обычным массивом метод вернёт true (если они будут эквивалентны). Чтобы решить это, нужно сравнить сначала значения на объекты, потом отдельно на массивы.
