Рубрика «Решаем вместе»: queryString

В веб-разработке указание query-параметров вместе с URL — это самый простой способ передать какую-либо информацию, поэтому преобразование объекта в query-строку довольно популярно.

В NodeJS есть встроенная библиотека querystring, а в браузере можно воспользоваться URLSearchParams, который поддерживается всеми современными браузерами (кроме IE11, если его ещё можно называть современным).

В этом уроке покажем, как реализовать такую функцию самостоятельно. Есть несколько условий: проверять, что на вход подали объект (иначе выкидывать ошибку 'input must be an object') и обрабатывать вложенные объекты и массивы.

Для начала понадобятся вспомогательные функции, которые были написаны в авторском решении isEqual, а именно isPlainObject, isArray, isArrayOrObject и тип PlainObject.

Первым делом реализуем версию, которая работает только с примитивами. Она довольно простая — нужно проитерироваться по всем ключам объекта и составить массив пар ключ- значение. После полученный массив массивов преобразовать в строку с помощью метода join. И да, не забудем проверить аргумент на объект:

function queryString(data: PlainObject): string {
  if (!isPlainObject(data)) {
    throw new Error('input must be an object');
  }

  const result: [string, string][] = [];

  for(const [key, value] of Object.entries(data)) {
    result.push([key, String(value)]);
  }

  return result.map(arr => arr.join('=')).join('&');
}

// result = [[foo, bar], [baz, 5], [xyz, false]]
queryString({ foo: 'bar', baz: 5, xyz: false }); // foo=bar&baz=5&xyz=false

Если в Object.entries передать массив, то на выходе получится массив пар, где первым элементом будет индекс массива, а вторым — значение. Это удобно использовать, если для массивов и объектов одинаковая обработка. Но если попробуем передать вложенный объект, то в ответ получим [object Object]:

queryString3({ foo: { baz: 5 } }); // foo=[object Object]

Объекты и массивы необходимо обрабатывать рекурсивно. Но есть сложность, что для вложенных значений нужно формировать также ключ. Например, выше ответ должен быть равен foo[baz]=5. Для этого можно добавить второй параметр функции, в котором будет храниться родительский ключ.

Создадим функцию getKey, которая будет формировать ключ:

function getKey(key: string, parentKey?: string) {
	return parentKey ? `${parentKey}[${key}]` : key;
}

Самый простой вариант — ввести ещё одну дополнительную функцию, которая будет возвращать только массив пар, чтобы была возможность агрегировать результат:

function getParams(data: PlainObject | [], parentKey?: string) {
  const result: [string, string][] = [];

  for(const [key, value] of Object.entries(data)) {
    if (isArrayOrObject(value)) {
      result.push(...getParams(value, getKey(key, parentKey)));
    } else {
      result.push([getKey(key, parentKey), String(value)]);
    }
  }

  return result;
}

Итоговое решение

type PlainObject<T = unknown> = {
  [k in string]: T;
};

function isPlainObject(value: unknown): value is PlainObject {
  return typeof value === 'object'
    && value !== null
    && value.constructor === Object
    && Object.prototype.toString.call(value) === '[object Object]';
}

function isArray(value: unknown): value is [] {
  return Array.isArray(value);
}

function isArrayOrObject(value: unknown): value is [] | PlainObject {
  return isPlainObject(value) || isArray(value);
}

function getKey(key: string, parentKey?: string) {
  return parentKey ? `${parentKey}[${key}]` : key;
}

function getParams(data: PlainObject | [], parentKey?: string) {
  const result: [string, string][] = [];

  for(const [key, value] of Object.entries(data)) {
    if (isArrayOrObject(value)) {
      result.push(...getParams(value, getKey(key, parentKey)));
    } else {
      result.push([getKey(key, parentKey), encodeURIComponent(String(value))]);
    }
  }

  return result;
}

function queryString(data: PlainObject) {
  if (!isPlainObject(data)) {
    throw new Error('input must be an object');
  }

  return getParams(data).map(arr => arr.join('=')).join('&');
}
