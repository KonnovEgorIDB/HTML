Работа с файлами

Отправка файлов на сервер отличается способом создания запроса. Отличаться будут заголовки и тело запроса.

Сделаем форму для работы с файлом:

<form id="myUserForm">
  Картинка: <input id="avatar" type="file" name="avatar" accept="image/*">
  <input type="submit">
</form>

Напишем обработчик для формы:

<script>
const host = 'https://ya-praktikum.tech';
const myUserForm = document.getElementById('myUserForm');

myUserForm.addEventListener('submit', event => {
  event.preventDefault();

  const avatar = document.getElementById('avatar');
  const form = new FormData(myUserForm);

  // Можете добавлять свои дополнительные поля или составлять данные полностью из пустой FormData
  // Если хотите назвать файлы как-то иначе, третий параметр по-вашему усмотрению
  // form.append('avatar', avatar, 'my-file-name.png');

  fetch(`${host}/api/v2/user/profile/avatar`, {
    method: 'PUT',
    credentials: 'include', // Нам нужно подставлять cookies
    mode: 'cors', // Работаем с CORS
    body: form,
  })
    .then(response => response.json())
    .then(data => {
      console.log(data);
      return data;
    });
  });
</script>

Теперь работа с данными изменилась с формата JSON на form-data (имеется ввиду content-type: multipart/form-data). Поэтому вместо JSON.stringify используется FormData.

Указывать заголовок Content-Type не нужно, браузер сам его подставит: multipart/form-data + хеш (контрольная сумма) от данных.

После выбора аватара, будет отправлен запрос в ручку /api/v2/user/profile/avatar. У запроса будет метод PUT, а его body принимает сразу FormData.

После отправки запроса по нажатию на кнопку submit, в заголовках также проставились нужные cookies.
