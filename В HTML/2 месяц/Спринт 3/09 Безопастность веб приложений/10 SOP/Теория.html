SOP

Правило ограничения домена (Same Origin Policy, то есть «принцип одинакового источника» или «политика единого источника») — это важная концепция и политики безопасности, и работы веб-приложений. Она ограничивает возможности пользовательских сценариев из определённого источника по доступу к ресурсам и информации из других источников.

На MDN можно подробнее почитать про эту политику.

В ней есть понятие «источник» — это адрес в интернете, откуда был загружен ресурс. Два URL считаются имеющими один источник (“same origin”), если у них одинаковый протокол, домен и порт.

У данных ресурсов одинаковые источники:

  • http://site.com,
  • http://site.com/,
  • http://site.com/my/page.html.

А у этих источники разные:

  • http://site.com,
  • http://www.site.com — другой домен,
  • http://site.org — другой домен,
  • https://site.com — другой протокол,
  • http://site.com:8080 — другой порт.

Способы взаимодействия с ресурсами в WEB-приложениях можно отнести к одной из трёх категорий:

  • Запись в ресурсы — например: перейти по ссылке, сделать редирект, засабмитить форму или отправить ресурсы;
  • Встраивание ресурсов в другие ресурсы:
    • JavaScript с помощью <script src="..."></script>,
    • CSS с помощью <link rel="stylesheet" href="...">,
    • Картинки с помощью <img>,
    • Медиафайлы с помощью <video> и <audio>,
    • Плагины с помощью <object>, <embed> или <applet>.
  • Чтение из других ресурсов — например: читать ответы на запросы, получение доступа к содержимому встроенного ресурса.

Способы взаимодействия соотносятся с Same Origin Policy следующим образом:

  • Cross Origin запись в ресурсы по умолчанию разрешается, но о некоторых исключениях расскажем ниже;
  • Cross Origin по умолчанию разрешает встраивание ресурсов;
  • Cross Origin по умолчанию запрещает чтение из других ресурсов.

Вместе с SOP стоит использовать специальные атрибуты cookie:

Set-Cookie: id=1111; Path=/admin/
Set-Cookie: id=2222; Path=/; Domain=my.example.com
Set-Cookie: id=3333; Path=/; Http-Only; secure

Http-Only - кука не доступна из JS
Secure - кука передаётся только по HTTPS

Cross-Origin Resource Sharing — это механизм, который при использовании дополнительных HTTP-заголовков даёт возможность агенту пользователя получать разрешение на доступ к ресурсам сервиса. Подробнее можно почитать на MDN.

Пример запроса и ответа с заголовками:

GET /handler/ HTTP/1.1
Host: myawesomedomain.com
Origin: https://attacker.com
Cookie: session=123

HTTP/1.0 200 OK
Access-Control-Allow-Origin: https://attacker.com
Access-Control-Allow-Credentials: true
