Собираем пример

Создадим проект, где будет:

  • ES6+,
  • TypeScript,
  • подключение SVG как модуль,
  • работа с SCSS.

Использовать будем утилиту identity:

import identity from '__utils/identity';
import Logo from '__assets/ya-praktikum.png';

import '__styles/main.scss';

const logo = document.createElement('img');
logo.src = Logo;

const greeting = document.createElement('h1');
greeting.textContent = identity('Header');

const app = document.querySelector('#root');
app.append(greeting, logo);

Этот пример и даже больше можете посмотреть на GitHub.

В проекте содержатся:

  • *.ts файлы — TypeScript,
  • *.scss — стили,
  • *.png — картинки,
  • и многое другое.

Картинки будем добавлять в проект инлайново, то есть вставлять внутрь JS-файлов. Стили вынесем отдельными файлами-бандлами.

Сборка состоит из четырёх частей:

  1. Входные и выходные пути;
  2. Загрузчики, обработчики и свойства для обработки скриптов;
  3. Загрузчики, обработчики и свойства для обработки стилей;
  4. Загрузчики, обработчики для всего остального: картинки, кастомные форматы.

Добавим в проект следующие зависимости:

npm i --save-dev webpack webpack-cli

Эти библиотеки необходимы для запуска сборки и удобного управления командами.

Полезные утилиты для работы со сборками и проектами:

  • webpack-dev-server — агрегация Express-сервера, который описывается небольшим конфигурационным файлом. Утилита умеет работать с прокси, локейшенами, автооткрытием браузера и другими полезными настройками;
  • webpack-merge — утилита для слияния Webpack-конфигов. По сути, просто глубокий merge, в котором сохраняются вложенные элементы массивов и объектов.

Об этих утилитах поговорим далее. Начнём с простой компиляции и сборки проекта.

Достаточно написать несколько файлов:

// identity.ts

export default function identity<T>(arg: T): T {
return arg;
}

// module.ts

import identity from './identity';

const data = identity('test');
export default data;

// index.ts

import data from './module';
import identity from './identity';

console.log(data);
console.log(identity({test: 'test'}));

Итого в проекте три файла, он работает с ES6+, и разные модули импортируются друг в друга. Если начать подключать подобное в браузер через тег script, то:

  1. Не все браузеры поддерживают ES6 импорты;
  2. TypeScript нужно скомпилировать, а для этого придётся добавлять команды вручную.

Напишем простой сборщик TypeScript без index.html для компиляции JS-кода:

// webpack.config.js

const path = require('path');

module.exports = {
  mode: 'development',
  entry: './index.ts',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'project-name.bundle.js'
  },
  resolve: {
    extensions: ['.ts', '.js', '.json']
  },
  module: {
    rules: [
      {
        test: /\.tsx?$/,
        use: [
          {
            loader: 'ts-loader',
            options: {
              configFile: path.resolve(__dirname, 'tsconfig.json'),
            },
          },
        ],
        exclude: /(node_modules)/
      }
    ]
  }
};

Для запуска Webpack достаточно одной команды:

node ./node_modules/.bin/webpack

Появится папка dist, в которой будет лежать файл project-name.bundle.js. В нём будет скомпилированный код, который через IIFE и eval запустит необходимый JS-код. Сборка не минифицирована, только для разработки.

Чтобы сделать сборку быстрее, лучше и без дубликатов — необходимо подключать дополнительные опции.

Чтобы подключить Sass и PNG — используйте sass-loader и url-loader. У каждого лоадера есть свой набор опций. Чтобы подключить Sass, сначала нужно обработать его Sass-лоадером, а затем CSS-лоадером. Такая последовательность позволит из JS-кода получить доступ к CSS-дереву.
