В этом уроке напишем собственный лоадер. Это совсем не страшно и сейчас вы сами в этом убедитесь.

Есть SCSS-файл. У него есть класс, который импортируется общим блоком:

.Button {
	&__size { ... }
}

import b_ from 'b_';

import './button.scss';
...
buttonWrapper.className = b_('button', 'size', {large: true});
buttonText.className = b_('button', 'color', {black: true});

Во-первых, очень много дублирования b_('button'. Во-вторых, непонятно дублируются ли стили. В-третьих, было бы очень удобно писать вот так:

import {b as bButton} from './button.scss';
...
buttonWrapper.className = bButton('size', {large: true});
buttonText.className = bButton('color', {black: true});

Да, есть CSS-modules, которые возвращают JS-объект. В нём даже может быть типизация. Но если вы сторонник БЭМ и пользуетесь утилитой b_, то почему бы не совместить приятное с полезным.

Напишем такой лоадер, который при обработке Sass-файла, будет позволять из TypeScript импортировать утилиту b_ с уже вызванным префиксом.

Лоадер — это просто функция, которая на вход принимает контент и обладает контекстом, доступным для использования.

Наш лоадер будет находить в начале файла имя класса и подставлять его в b_: b_.with(foundClass).

const fs = require('fs');

// Модуль должен идти после css-loader
module.exports = function loader(content) {
  this.addDependency(this.resourcePath);

  // css-loader не даёт возможности получить доступ к AST дереву
  // https://github.com/webpack-contrib/css-loader/blob/master/src/index.js
  const css = fs.readFileSync(this.resourcePath, 'utf-8');
  const match = css.match(/\.([a-z-_0-9]+)/i);

  if (!match) {
    return content;
  }

  return [
    content,
    `module.exports.b = require('b_').with('${match[1]}');`
  ].join('\n');
};

Таким образом, теперь можно импортировать Sass-файлы с утилитой b_ почти «из коробки» с помощью нескольких строчек лоадера.

Кастомный лоадер подключается к CSS и Sass-файлам так же, как и обычный сторонний:

const cssLoaders = [
  {loader: './webpack/loaders/b_-loader/loader.js'},
  MiniCssExtractPlugin.loader,
  {loader: 'css-loader'},
];

rules.push(
	{
	  test: /\.css$/,
	  use: cssLoaders,
  },
	{
    test: /\.scss$/,
    use: [...cssLoaders, {loader: 'sass-loader'}],
  },
);
