Рубрика «Решаем вместе»: Bind

«Напишите свой bind» — это очень частый вопрос на собеседованиях. Почему? Потому что в зависимости от ответа можно понять, насколько кандидат разбирается в работе контекста в JavaScript.

Что вообще делает bind? Он привязывает контекст вызова функции и, в отличие от call и apply, не вызывает её сразу. Если говорить более точно, то bind возвращает новую функцию с заданным контекстом.

Чтобы правильно написать bind самому, сначала необходимо внимательно изучить интерфейс функции:

  • Функция bind не вызывает переданную функцию (fn), а всего лишь задаёт ей контекст;
  • Функция bind может принимать неограниченное количество аргументов. Кроме первых двух, в которых задана функция (fn) и контекст, все остальные должны быть переданы в функцию при её вызове;
  • Полученной функции можно также передать сколько угодно аргументов;
  • Если в качестве функции (fn) передать не функцию, то должна быть выброшена ошибка. Можете проверить:
Function.prototype.bind.call({})
VM686:1 Uncaught TypeError: Bind must be called on a function

Перейдём к реализации и сначала напишем заготовку:

function bind(fn, context) {
	return function () {
		return fn();
	};
}

Чтобы вызвать функцию в нужном контексте, воспользуемся методом call:

function bind(fn, context) {
	return function () {
    // Вызываем fn в контексте context
		return fn.call(context);
	};
}

Теперь разберёмся с аргументами. Для их получения воспользуемся оператором spread и при вызове fn передадим их:

function bind(fn, context, ...boundArgs) {
	return function (...args) {
    // Вызываем fn в контексте context
		return fn.call(context, ...boundArgs, ...args);
	};
}

До ES6, когда у разработчиков не было в арсенале оператора spread (...), все аргументы функции можно было забрать из массивоподобного объекта — arguments. Так как это не настоящий массив, обычно его приводили к массиву с помощью вызова slice в контексте следующего объекта:

const args = Array.prototype.slice.call(arguments)

К счастью, со spread код стал понятнее и проще. Последнее, что нужно сделать, это проверить, что в качестве fn передана функция. Финальный вариант:

function bind(fn, context, ...boundArgs) {
    // Проверяем fn на функцию
    if (typeof fn !== 'function') {
      throw new TypeError('Bind must be called on a function');
    }

	return function (...args) {
    // Вызываем fn в контексте context
		return fn.call(context, ...boundArgs, ...args);
	};
}

Допустим, есть функция, которая суммирует все переданные аргументы, а в качестве начального значения берёт из контекста this.initialSum:

function sum(...args) {
	return args.reduce((acc, num) => {
    return acc + num;
  }, this.initialSum);
}

При обычном вызове функция всегда будет возвращать NaN, так как this.initialSum будет равен undefined, а при сложении числа с нечисловым типом результатом будет NaN:

sum(10, 20); // NaN = undefined + 10 + 20

Воспользуемся функцией bind:

const ctx = {initialSum: 1000};
const boundSum = bind(sum, ctx);

boundSum(10, 20); // 1030 = 1000 + 10 + 20

Можем также передать аргументы по умолчанию:

const ctx = {initialSum: 1000};
const boundSum = bind(sum, ctx, 1000);

boundSum(10, 20); // 2030 = 1000 + 1000 + 10 + 20

Отлично, всё работает, как и ожидалось! Ещё одно интересное замечание: в отличие от обычных функций, у стрелочных нельзя менять контекст, даже вызывая их с call или apply.

const ctx = {num: 100}
const add = function(x) {
	return this.num + x;
}

console.log(add.call(ctx, 1)) // 101 = 100 + 1

const addInArrow = x => this.num + x;
console.log(addInArrow.call(ctx, 1)) // NaN = undefined + 1
