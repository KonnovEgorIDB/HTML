CDN на примере

CDN предоставляет «из коробки»:

  • кеширование,
  • сжатие текстовой статики,
  • обеспечение 100% доступности.

У него прописаны политики кеширования, «устаревания» статики и количества точек присутствия (point of presence). Точка присутствия — это кеширующий сервер в составе CDN, который находится в определённой географической локации.

Статику можно держать в отдельной папке, например, public:

app/
└── index.js
└── routes.js
└── models
└── controllers
└── views
└── public
    └── styles.css
    └── favicon.ico

При сборке в Webpack можно настроить какие файлы попадут в отдельную папку public и занести эту папку в CDN.

В сборке можно указать, чтобы на выходе в HTML подставлялся не ./styles.css, а https://cdn.url/path/to/styles.css:

<head>
  <link rel="stylesheet"
	      href="https://my-app.surge.sh/styles.css">
</head>

Одним из самых простых способов занести свои файлы в CDN — это ресурс Surge.

Установить Surge можно даже через npm:

~$ npm install surge
~$ surge -p ./public -d my-app.surge.sh

Ещё один популярный способ хранить статику — S3. Amazon создал универсальное API для управления статикой. Оно «перекочевало» в другие сервисы. Теперь S3 есть также в Digital Ocean, Yandex.Cloud, Google.Cloud.
