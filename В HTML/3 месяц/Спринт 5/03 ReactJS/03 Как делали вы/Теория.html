Как делали вы?

В прошлом модуле у вас были задачи на реализацию компонента со своим жизненным циклом и свойствами.

Пример того, как мог выглядеть ваш компонент:

import Button from "./components/button";
import Text from "./components/text";
import { render } from "./utils/rednerDOM";

const button = new Button({
	className: 'my-class',
	child: new Text({ text: 'Click me' }),
});

render(".app", button);

Сравним с сигнатурой React из прошлого урока:

ReactDOM.render(
  React.createElement(
    'div', { id: 'test' },
    React.createElement('h1', null, 'A title'),
    React.createElement('p', null, 'A paragraph')
  ),
  document.getElementById('root')
);

В результате первого модуля вы попробовали реализовать примерную модель компонентного подхода разработки. Было предложено решение через Event Bus и Proxy-объекты для отслеживания изменения свойств и запуска жизненного цикла компонента.

Теперь у вас есть представление, как работает React, — без магии. Всё работает через паттерны и JavaScript. Также там задействованы подписки и события, «прослушка» изменения свойств и другие вещи, которыми вы занимались весь первый модуль.
