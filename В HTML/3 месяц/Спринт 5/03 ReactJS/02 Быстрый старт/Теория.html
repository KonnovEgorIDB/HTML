Быстрый старт

Начнём с простого — создадим компонент, который реализует div с текстом «Привет из Реакта!».

Для этого сделаем index.html страницу с ReactJS из CDN:

<html>
  <head></head>

  <body>
    <div id="root"></div>
	
    <script crossorigin="" src="https://unpkg.com/react@16/umd/react.production.min.js"></script>
    <script crossorigin="" src="https://unpkg.com/react-dom@16/umd/react-dom.production.min.js"></script>

    <script type="module">
      ReactDOM.render(
        React.createElement(
		  'div', { id: 'test' },
		  React.createElement('h1', null, 'A title'),
		  React.createElement('p', null, 'A paragraph')
       ),
      document.getElementById('root')
	);
	</script>
  </body>
</html>

Рассмотрим код детальнее. ReactDOM нужен для того, чтобы встроить React-элемент в DOM-дерево. Метод render принимает React-элемент, а также DOM-элемент, в который нужно встроить весь контент. В данном случае весь контент будет внутри div с id, значение которого root.

Теперь перейдём к самому React-элементу. Он будет создан с помощью функции createElement. Первые два аргумента функции — это тег (или другой компонент, об этом поговорим дальше) и параметры или свойства компонента. Третий аргумент через ...rest — это другие компоненты, которые можно передавать как детей текущего компонента. И так рекурсивно со всеми остальными.

В примере у элементов h1 и p дети — это просто строки, но ими могут быть почти любые объекты. Подробнее вы можете посмотреть в коде с типами React. Про саму типизацию React мы поговорим в следующих темах этого спринта, так что далеко не уходите.

Каждый компонент обладает:

  • свойствами,
  • жизненным циклом,
  • внутренней машиной состояний.

Обратите внимание на плагин React Dev Tools. Для Chromium-браузеров его можно найти тут. Статья «Дебажьте как ниндзя» поможет понять, зачем использовать данную утилиту. Если кратко — удобно смотреть разметку и проверять код профайлером.
