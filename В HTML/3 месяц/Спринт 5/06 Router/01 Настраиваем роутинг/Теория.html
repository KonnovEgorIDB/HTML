Настраиваем роутинг

Роутер — это неотъемлемая часть любого веб-приложения, где нужно обрабатывать состояния пользователя или сервиса.

С помощью URL можно понять, например, где пользователь остановился, какой товар смотрит, в каком режиме открыл форму (чтение, редактирование).

Чтобы начать использовать роутер в React, вам понадобится библиотека react-router. Для работы с DOM-роутером используется библиотека react-router-dom, которая включает в себя react-router. Установите react-router-dom:

~$ npm install --save react-router-dom

Чтобы использовать роутинг, нужно сначала обернуть всё приложение в роутер. Есть два варианта: BrowserRouter — для работы с динамическими сервисами и HashRouter — для работы со статическими сайтами.

HashRouter подходит, например, для сайта-визитки или документации с якорными ссылками.

Сервис оборачивают вот так:

export default class App extends PureComponent {
  public render() {
    return (
      <div className="app">
        <Router>
          ...
        </Router>
      </div>
    );
  }
}

С помощью свича (Switch) можно группировать роуты. Например, есть раздел /user, а внутри могут быть ещё URL:

  • /user/:id,
  • /user/action,
  • /user/:id/some-url.

В таком случае лучше обернуть в <Switch>. Даже / стоит обернуть в него.

export default class App extends PureComponent {
  public render() {
    return (
      <div className="app">
        <Router>
          <div>
						<Switch>
							<Route path="/" .../>
							<Route path="/users" .../>
							<Route path="/about">...</Route>										
						</Switch>
					</div>
        </Router>
      </div>
    );
  }
}

Задают роуты с помощью Route:

// Можно так:
<Route path="/user/:id" component={User}/>

// А можно и так:
<Route path="/user/:id">
  <User/>
</Route>

Точное совпадение с URL можно задать через свойство exact:

// Если будет урл /user/1/bla — этот роут не сработает
<Route path="/user/:id" exact component={User}/>

С помощью калькулятора роутов потренируйтесь «дебажить» их. А эта статья более детально расскажет про установку роутера и покажет дополнительные примеры его использования.
