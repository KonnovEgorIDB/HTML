Напутствие по структуре проекта

Старайтесь придерживаться во всём проекте единой архитектуры папок и файлов. Поначалу это придётся отслеживать руками. Чтобы упростить — сделайте шаблоны и сниппеты кода в IDE или редакторе кода, чтобы не писать всё руками.

Дальше, если понадобится, напишите специальные правила для линтера или даже плагин для Webpack, который проверяет, что у всех компонентов и других сущностей нужная для вас структура, и никто её не поломал.

Вернёмся к самой структуре:

Начнём с самого простого — шаблон HTML. Храните его, например, в папке public или www. Часто встречается и там, и там. В шаблон index.html вы можете вставлять много метатегов, CPS (Content Security Policy) и прочее. Подробнее почитайте в плагине html-webpack-plugin.

В каталоге src/utils лучше хранить общие утилиты. Не держите все 100500 утилит в одном месте, разбивайте их на файлы. Даже один файл (одна атомарная утилита) — это круто!

Переходим к компонентам. Начнём со структуры файлов. Рассмотрим на примере Button:

  • Button.css — это файл со стилями. Может быть препроцессор или CSS-модули, что душе угодно;
  • Button.tsx — это файл только с реализацией компонента, без констант или типов:
import React, {FC} from 'react';

import {Props} from './types';

const Button: Props = ({children, ...otherProps}) => {
 return (
	 <button {...otherProps}>{children}</button>
 );
};
export default Button;
  • types.ts — это файл с типами компонента:
import {FC, ButtonHTMLAttributes} from 'react';

export type OwnProps = {
	myCustomProp?: 'some' | 'other';
} & ButtonHTMLAttributes<HTMLButtonElement>;

export type Props = FC<OwnProps>;
  • index.ts — это входная точка в любой компонент, которая содержит импорты нужных типов или компонентов.
import {memo} from 'react';

import Button from './Button';
import {OwnProps} from './types';

export default memo<OwnProps>(Button);

Даже если нет компонентов высшего порядка, можно писать вот так:

// components/App/index.ts

export {default} from './App';

Это также единое место, где всё обвязывается компонентами высшего порядка (покажем пример, который будет малопонятен, но в следующем спринте подробнее разберём этот случай):

import compose ...;
import withRouter ...;
import connect ...;

import someOurHoc ...;

import Component from './Component';
import {OwnProps} from './types';

export default compose<ComponentClass<OwnProps>>(
  connect(),
  withRouter,
  someOurHoc({ ... }),
)(Component);

С тестами точно так же. Если у кнопки есть тесты, держите их рядом с ней.
