Способы реализации UI

Для увеличения скорости разработки, упрощения реализации общих компонентов и просто для удобной работы используют паттерн «Модуль». Модулем может быть как шаблон с кнопкой, так и файл (или набор кода) любого инструмента для агрегации шаблонов.

Веб-компоненты

Стандарт позволяет делать шаблоны без всяких дополнительных библиотек — элемент template. Внутри него может быть как кнопка, так и стили:

<template>
  <div>Контент</div>
</template>

<template>
  <style>
    // Стили
  </style>
  <script>
    alert('Здравствуйте');
  </script>
</template>

Темплейты отлично сочетаются с Shadow DOM, что позволяет инкапсулировать реализацию тех или иных компонентов ещё проще.

Один из интересных способов разрабатывать интерфейсы нативным JavaScript — добавлять пользовательские элементы (custom elements). Допустим, вы делаете свой сервис, в котором есть компонент кнопки. Но кнопка не простая (а золотая), а содержит в себе некую реализацию с поддеревом. Дальше в коде хочется использовать новый тег <my-suppper-button></my-suppper-button> вместо копирования или дублирования реализации.

Существует два вида пользовательских элементов (ПЭ):

  1. Автономные ПЭ — это «новые» (созданные вами в рамках проекта) элементы, расширяющие абстрактный класс HTMLElement;
  2. Пользовательские встроенные элементы — это элементы, которые расширяют встроенные элементы, например, кнопку (HTMLButtonElement).

Пример из «Современного учебника JavaScript» покажет, как можно сделать нечто подобное самим:

<script>
class TimeFormatted extends HTMLElement {

  connectedCallback() {
    let date = new Date(this.getAttribute('datetime') || Date.now());

    this.innerHTML = new Intl.DateTimeFormat("default", {
      year: this.getAttribute('year') || undefined,
      month: this.getAttribute('month') || undefined,
      day: this.getAttribute('day') || undefined,
      hour: this.getAttribute('hour') || undefined,
      minute: this.getAttribute('minute') || undefined,
      second: this.getAttribute('second') || undefined,
      timeZoneName: this.getAttribute('time-zone-name') || undefined,
    }).format(date);
  }

}

customElements.define("time-formatted", TimeFormatted);
</script>

<time-formatted datetime="2019-12-01"
  year="numeric" month="long" day="numeric"
  hour="numeric" minute="numeric" second="numeric"
  time-zone-name="short"
></time-formatted>

Результат можно увидеть здесь. Данная глава из современного учебника показывает почти все нужные кейсы и как работать с этим инструментом.

Shadow DOM, template и пользовательские элементы — все вместе образуют совокупность стандартов, именуемую «Веб-компоненты». Подробнее про это можно почитать:

Шаблонизаторы

Ещё один способ делать компоненты и модули — это шаблоны. Но не «нативные», а с помощью библиотек.

С шаблонизаторами вы разбирались в прошлом модуле, потому механизмы вам уже знакомы.

JSX

JSX — это HTML-подобный «язык» для создания разметки:

const element = (
  <div id="test">
    <h1>A title</h1>
    <p>A paragraph</p>
  </div>
);

На первый взгляд кажется, что это обычный HTML (равно как и с шаблонизаторами). «Под капотом» всё также трансформируется в JavaScript. Как правило, у файлов, которые используют JSX, расширение не просто .js или .ts, а .jsx или .tsx, однако это необязательное условие.
