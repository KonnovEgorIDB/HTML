Осталось написать обработчики.

По порядку. Сначала реализуем функцию, которая отслеживает изменения букв в инпуте нового списка:

const handleChangeAddElementInput = useCallback((event) => {
  setText(event.target.value);
}, []);

Функция принимает event, так как мы прокидываем её вот так: onChange={handleChangeAddElementInput}. event от синтетического события, потому можем получить value, будто бы мы получили событие DOM-элемента через target.value.

С помощью функции setText обновим состояние инпута.

Теперь реализуем кнопку добавления:

const handleAdd = useCallback(() => {
  setTodos([ ...todos, { title: text, id: todos.length + 1 } ]);
}, [text, todos]);

Здесь происходит то же самое — добавляем в стейт данные.

Метод фильтрации работает аналогично методу handleChangeAddElementInput, потому описывать его не будем, но ниже по ссылке на репозиторий сможете найти его реализацию.

Остался всего один хендлер — удаление элемента из списка. Тут необходимо пробросить хендлер с контекстом каждой строки в списке.

const handleRemove = useCallback((id: number) => {
  setTodos(todos.filter((item: Todo) => item.id !== id));
}, [todos]);

Важно не забыть, что при клике на кнопку удаления нужно пробрасывать id:

<ul>
  {todos
    .filter((item: Todo) => item.title.includes(filterText))
    .map(({title, id}) => (
      <li key={id}>
        <span>{title} ({id})</span>
        <Button onClick={() => handleRemove(id)}>
          Удалить
        </Button>
      </li>
    ))
  }
</ul>

Используется это так: в onClick кнопки у каждого элемента списка будет вызван handleRemove с нужным id. Теперь появилась возможность фильтровать по нужному элементу.
