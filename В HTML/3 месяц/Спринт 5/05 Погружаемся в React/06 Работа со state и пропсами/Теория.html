Работа со state и пропсами

State

Локальный state (в переводе «состояние») компонента нужен только в том случае, если вы не хотите передавать данные между детьми и другими компонентами.

Для всего остального есть контекст или модели хранения данных (например, Flux, Redux, MobX, XState), о которых поговорим дальше. В этом спринте вам нужно будет использовать только состояние даже для пробрасывания свойств между детьми и глубже.

Рассмотрим пример, когда используется state. Возьмём инпут, который будет сохранять данные из введённого поля:

export default class Input extends PureComponent {
  state = {
    value: ""
  };

  handleChange = event => {
    this.setState({ value: event.currentTarget.value });
  };

  render() {
    const { value } = this.state;

    return (
      <input
        value={value}
        onChange={this.handleChange}
      />
    );
  }
}

Если нужно, в state определяем значения по умолчанию. В данном случае это будет пустая строка. Сделали метод для обработки события onChange. Он собирает данные из события и обновляет state. После изменения состояния компонент будет перерисован с новым значением value для инпута.

Пропсы

Пропсы — это свойства, которые пробрасываются от родителя к ребёнку:

function Children({name}) {
  return <p>{name}</p>; // <p>Иннокентий</p>
}

function App() {
  return <Children name="Иннокентий"/>;
}

Все пропсы получаются в виде обычного объекта. То есть передавать можно любые ключ-значения любой вложенности:

function Children({name, someProps, unexpectedProp}) {
  console.log(someProps); // {key1: 1, key2: {keyKey1: 11}}
  console.log(unexpectedProp); // undefined

  return <p>{name}</p>; // <p>Иннокентий</p>
}

function App() {
  const someProps = {key1: 1, key2: {keyKey1: 11}};
  return <Children name="Иннокентий" someProps={someProps}/>;
}

Пропсы можно передавать спредом:

function Children({name, key2, unexpectedProp}) {
  console.log(key2); // {keyKey1: 11}

  return <p>{name}</p>; // <p>Иннокентий</p>
}

function App() {
  const someProps = {name: 'Иннокентий', key2: {keyKey1: 11}};
  return <Children {...someProps}/>;
}

А можно и переопределять свойства:

function Children({name, key2, unexpectedProp}) {
  console.log(key2); // {keyKey1: 11}

  return <p>{name}</p>; // <p>Оля</p>
}

function App() {
  const someProps = {name: 'Иннокентий', key2: {keyKey1: 11}};
  return <Children {...someProps} name='Оля'/>;
}

Именно поэтому важно понимать, хотите вы делать spread до или после определения остальных свойств. То есть если вы хотите, чтобы spread-пропсы всегда переопределяли свойства, которые были описаны отдельно — нужно делать после, иначе (а лучше по умолчанию): сначала spread-пропсы, затем дописываете свойства.

Более подробно об этом написано в документации.
