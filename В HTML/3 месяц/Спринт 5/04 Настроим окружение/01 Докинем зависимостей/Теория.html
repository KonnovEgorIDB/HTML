Webpack нам будет нужен для того, чтобы удобный, красивый и читаемый код превратился в неудобный для человека, оптимальный для машины и работающий в необходимых браузерах.

Добавим его в проект:

~$ npm install webpack webpack-cli --save-dev

Последняя утилита нужна, чтобы была возможность удобно запускать Webpack в командной строке.

Теперь установим ReactJS:

~$ npm install react react-dom --save

Это уже основные зависимости проекта, потому используем ключ --save.

В прошлых уроках рассматривали синтаксис JSX, который позволяет писать декларативный и удобный код. Однако он не «заведётся» в браузере. Для начала нужно произвести транспайлинг JSX-разметки в JavaScript код.

Отличный транспайлер — Babel. Установим необходимые зависимости:

~$ npm install @babel/core babel-loader @babel/preset-env @babel/preset-react --save-dev

Утилиты в зависимостях:

  • @babel/core — преобразование ES6 в ES5;
  • babel-loader — лоадер для Webpack, который будет делать транспайлинг кода. То есть все прошедшие через бандлер файлы пройдут и через транспайлер (вы так настроите);
  • @babel/preset-env — пресет, который помогает Babel транспилировать код ES6/7/8 в ES5;
  • @babel/preset-react — пресет, который преобразует JSX в JavaScript код.

Для работы со стилями нужны следующие лоадеры:

~$ npm install css-loader style-loader --save-dev

css-loader объединит все CSS-файлы в один, а style-loader добавит все стили внутрь тега документа style. Это упрощённая модель, которую используем для тестового проекта. В ваших работах могут потребоваться дополнительные лоадеры для стилей.

В этой теме настроим простейший проект с CSS. Дальше вы можете настроить хоть PostCSS, хоть препроцессоры. Но мы рекомендуем настроить сразу PostCSS.

Добавим плагин для Webpack — он будет генерировать index.html на основе шаблона, который будет подан ему на входе:

~$ npm install html-webpack-plugin --save-dev

И последнее, что понадобится — это утилита для удобной и быстрой разработки проектов:

~$ npm install webpack-dev-server --save-dev
