Перехват ошибок

Существует несколько способов обработки ошибок. Например, использовать try {} catch() {}. Код с ошибкой:

const a = {};

a.b.c(); // Uncaught TypeError: Cannot read property 'c' of undefined 
		 // at <anonymous>:3:5

Ловим её:

const a = {};

try {
	a.b.c(); // Uncaught TypeError: Cannot read property 'c' of undefined 
			 // at <anonymous>:3:5
} catch(error) {
	console.log(error); // Cannot read property 'c' of undefined
						// as <anonymous>:4:5
}

Однако обработка исключений — это «дорогая» операция. Как минимум потому, что она использует намного больше инструкций ассемблерного кода, то есть выполняется дольше.

Самый простой и быстрый способ обрабатывать ошибки — не доводить до них. То есть использовать if:

const a = {};

if (a && a.b && typeof a.b.c === 'function') {
  a.b.c(); // Не зайдём сюда
}

Но такой код писать банально неудобно. Что делать? Спасибо TypeScript за Optional Chaining из версии 3.7.2:

const a = {};

a?.b?.c?.();

Обработка ошибок в Vanilla JS

Нельзя предсказать всё и не избежать ошибок вида: TypeError: Cannot read property 'c' of undefined. Но можно научиться ловить такие ошибки и не «рушить» логику интерфейса. Чтобы поймать все ошибки, можно сделать обработчик на глобальный объект window:

/* middleware может принимать любое количество аргументов любых типов */

const middleware = (...args) => {
  const [event, ...data] = args;
  
  if (event.error) {
    /* поймали объект экземпляр Error */
    return event.error;
  }
  
  /* поймали непростое исключение, передаём дальше... */
  return data;
}

window.addEventListener('error', middleware);
window.onerror = middleware;

Добавим логов и попробуем использовать обработчик:

<script>
const middleware = (...args) => {
  const [event, ...data] = args;

  console.log(args);

  if (event.error) {
    return event.error;
  }

  return data;
}

window.addEventListener('error', middleware);
window.onerror = middleware;

const a = {};

a.b.c();
</script>

Лог события через addEventListener и через onError отличаются.

Ошибка при выполнении останется, но о ней уже известно, а значит, её можно обработать, то есть:

  • отправить на сервер,
  • сообщить пользователю о непредвиденной ошибке и что над ней уже ведутся работы,
  • делать с ней дальше всё, что хотите, так как теперь о ней известно.

Но что, если ошибка случилась в промисе:

<script>
  /* middleware может принимать любое количество аргументов любых типов */

  const middleware = (...args) => {
    const [event, ...data] = args;

    console.log(args);
    if (event.error) {
      /* поймали объект экземпляр Error */
      return event.error;
    }

    /* поймали непростое исключение, передаём дальше... */
    return data;
  }

  window.addEventListener('error', middleware);

  new Promise((resolve, reject) => {
    const a = {};

    a.b.c();

    resolve();
  });
</script>

При обновлении страницы не будет никакого лога в обработчике ошибки. Потому что данное событие не распространяется на промисы. Стоит воспользоваться дополнительным событием.

<script>
  /* middleware может принимать любое количество аргументов любых типов */

  const middleware = (...args) => {
    const [event, ...data] = args;

    console.log(args);
    if (event.error) {
      /* поймали объект экземпляр Error */
      return event.error;
    }

    /* поймали непростое исключение, передаём дальше... */
    return data;
  }

  window.addEventListener('error', middleware);

  window.addEventListener('unhandledrejection', (...args) => {
    console.log(args); // Лог будет здесь
  });

  new Promise((resolve, reject) => {
    const a = {};

    a.b.c();

    resolve();
  });
</script>

У этого события неплохая поддержка, но она не спасёт везде. Поэтому нужно либо написать свою обёртку над промисом с обработчиком ошибок через catch, либо воспользоваться транспайлерами.

Источник:https://caniuse.com

Можно реализовать функцию высшего порядка, чтобы быстро масштабироваться и «обвешивать» любые функции с обработчиками ошибок. Например, навесить такую функцию на обработчик события mousemove:

const callWithErrorHandler = middleware => e => {
  const { error } = e; // предположим, что ошибка в этом поле
  
  if (error) {
    throw new Error(error);
  }
  
  try {
    return middleware(e);
  } catch (err) {
    throw new Error(err);
  }
}

window.addEventListener('mousemove', callWithErrorHandler(someMouseMoveHandler));

Обработка ошибок в ReactJS

Ничего нового здесь нет. Всё так же можно написать компонент-обёртку, который перехватывает ошибки дочерних элементов.

Однако это не повод отказаться от способов для обработки JS-ошибок и промисов, так как в проекте не весь код находится внутри React-компонентов.

Можно реализовать отдельный компонент:

import React, {ErrorInfo} from 'react';

import {Props, State} from './types';

const {__PROD__} = process.env;

export default class ErrorBoundary extends React.PureComponent<Props, State> {
    public state: State = {
        error: null,
        errorInfo: null,
    };

    public componentDidCatch(error: Error, errorInfo: ErrorInfo) {
        this.setState({error, errorInfo});
    }

    public render() {
        const {children} = this.props;

        if (!__PROD__ && this.state.errorInfo) {
            return (
                <>
                    <h2>Что-то пошло не так.</h2>
                    <details style={{whiteSpace: 'pre-wrap'}}>
                        { this.state.error && this.state.error.toString() }
                        <br/>
                        { this.state.errorInfo.componentStack }
                    </details>
                </>
            );
        }

        return children;
    }
}

Или реализовать HOC, который можно применить в любой части проекта:

import React from 'react';

export const withErrorBoundaries = (Wrapped) => {
  class ErrorBoundary extends React.PureComponent {
    /* укажите уникальное название компонента, для упрощения отладки в DevTools */
    static displayName = `ComponentWithErrorBoundary(${Wrapped.name || 'Wrapped'})`;

    componentDidCatch(error, errorInfo) {
      middlewareErrorBoundary(error, errorInfo);
    }

    renderComponent = (context) => <Wrapped {...this.props} {...context} />;

    render() {
      return (
        <Consumer>
          {this.renderComponent}
        </Consumer>
      );
    }
  }
  
  return ErrorBoundary;
}
