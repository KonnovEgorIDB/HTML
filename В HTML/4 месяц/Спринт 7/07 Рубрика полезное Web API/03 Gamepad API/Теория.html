Gamepad API

Gamepad API — отличное дополнение к вашей игре! С его помощью вы сможете подключить джойстик в браузере (Chromium, Opera, Firefox) и управлять своим персонажем.

API совсем небольшое и работает на событиях. Так же, как и другие нажатия на клавиши или мышь.

Если у вас динамическая игра с передвижениями, стоит задуматься о его внедрении.

  • Описание на MDN;
  • W3C;
  • GamepadAPI или джойстик в браузере;
  • Использование от MDN.
