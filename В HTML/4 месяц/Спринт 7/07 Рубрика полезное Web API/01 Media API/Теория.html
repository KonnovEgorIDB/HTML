Media API

Web Media API — инструмент, который позволяет работать с медиаданными на клиенте. На W3C можно найти документацию.

Поддержка у функционала очень хорошая:

Источник:https://caniuse.com/

С помощью данного API можно управлять аудио- и видеофайлами. Можно запускать как уже готовые файлы, так и стримы (как радио, так и что-то вроде YouTube).

Например, с бэкенда вам прилетает буфер (набор байт), вы можете его динамически вставить на страницу или переиспользовать данные из него:

new Promise((resolve: (data: BufferFileType) => void) => {
  const media = document.createElement('video');
  const blobURL = URL.createObjectURL(new Blob([buffer]));

  media.addEventListener('loadedmetadata', () => {
    resolve({
	    duration: media.duration,
	    buffer: buffer,
    });
  });
  media.src = blobURL;
});

И возможность динамически пополнять буфер:

const mediaSource = event.target as MediaSource;
mediaSource.addSourceBuffer(mimeType);

Данный инструмент отлично подойдёт, если решите подключить стримминг, например из YouTube или Twitch, к себе в сервис.
