Ambient Light Events API

Ambient Light Events API — инструмент для автоматического изменения интерфейса в зависимости от освещённости.

Если устройство пользователя умеет реагировать на свет, то вы можете «подписаться» на изменение значений в люксах. В зависимости от них можно менять интерфейс пользователя: делать фоновый цвет ярче, темнее и т. д.

Подробнее об API:

  • MDN;
  • Знакомство с Ambient Light API;
  • Пример отзывчивого дизайна;
  • Мобильные веб-суперспособности.
