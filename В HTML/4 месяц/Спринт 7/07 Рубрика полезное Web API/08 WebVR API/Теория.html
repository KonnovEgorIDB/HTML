WebVR API

WebVR API — инструмент для работы с дополненной или виртуальной реальностью.

Примеры использования данной технологии (раз и два). Дополненная реальность для игр активно развивается, но остаётся очень сложной областью. Об этом API скорее полезно знать, чем использовать. Но вдруг вы захотите использовать его в вашем проекте? Звучит очень круто!

Подробнее про это API можно почитать на MDN и посмотреть примеры на Хабре. Часто WebVR используют вместе с Three.js или Babylon.js.
