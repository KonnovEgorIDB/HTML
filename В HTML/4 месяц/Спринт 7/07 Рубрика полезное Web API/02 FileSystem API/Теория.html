FileSystem API

FileSystem API — используется редко, но иногда может пригодиться. Поддержка браузерами стала лучше, но всё равно работает не везде.

Источник:https://caniuse.com/

Применять его нужно аккуратно. Не нужно запрашивать разрешение на FS (File System) у пользователя, если не планируете работать с его файловой системой. К счастью, создание, чтение и редактирование файлов у API работает в области пользовательской «песочницы».

Как и для некоторых других Web API, нужно просить разрешение на использование. Сделать это можно так:

window.requestFileSystem
