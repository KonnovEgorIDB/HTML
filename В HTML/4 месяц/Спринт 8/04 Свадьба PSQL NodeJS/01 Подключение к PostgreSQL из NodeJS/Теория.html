Подключение к PostgreSQL из NodeJS

В этой теме вы разберётесь с тем, что такое ORM и как с ней работать в приложениях на NodeJS. Но ORM — это высокоуровневый инструмент, и прежде чем перейти к нему, стоит узнать о том, как работать напрямую с базой из вашего приложения.

Драйвер

Любая СУБД занимается разными вещами:

  • организацией хранения данных на дисках и в памяти;
  • процессингом языка запросов;
  • управлением транзакциями и выполнением запросов;
  • и многим другим.

Но если к базе данных не иметь доступа — зачем она была бы нужна? База обретает смысл, когда с ней можно работать — работать либо из нашего кода с бизнес-логикой, либо из специальных программ для работы с БД, типа pgAdmin или DataGrip и других.

Для доступа к себе база данных даёт сокет, по которому производится обмен данными, соответствующими определённому протоколу. То есть когда мы открываем pgAdmin или DataGrip и соединяемся с базой — открывается сокет и по нему гоняют данные. Окей, эти программы большие и умные, а как быть нам с нашим кодом на NodeJS?

Можно «заморочиться», изучить протокол общения и написать вручную открытие сокета и обмен данными. Но, кажется, это слишком сложно. 🙂 Всё написано до нас.

Для работы с PostgreSQL из NodeJS уже существует написанная библиотека node-postgres, которая предоставляет удобный интерфейс над сокетом и протоколом базы. Такая библиотека называется драйвером базы данных. Драйвера существуют для всех распространенных баз, и вы легко найдёте драйвера для MongoDB, Redis, MySQL, Cassandra, Neo4j и других.

Кстати, можете покопаться в исходниках node-postgres — там не так уж много кода.

Установка и использование

Установите драйвер:

npm install --save pg

В npm библиотека называется pg, хотя в гитхабе node-postgres, учитывайте это.

Если на бэкэнде вы используете TypeScript — также поставьте типы для драйвера:

npm install --save-dev @types/pg

После можно начинать использовать. Возьмём пример из официальной документации и немного модифицируем его под Promise:

const { Client } = require('pg');

const client = new Client({
  user: 'postgres',
  host: 'localhost',
  database: 'my-db-name',
  password: 'newPassword',
  port: 5432,
});

client.connect();

client.query('SELECT NOW()').then(res => {
  console.log(res.rows);
  client.end();
}).catch(err => {
  console.log('error', err);
});

Не будем здесь полностью рассматривать возможности драйвера. Главное, что теперь у вас есть возможность напрямую связаться с базой и поделать туда запросы, получая ответы. Потренируйтесь с запросами, которые были в предыдущих уроках, и исполните их из приложения на NodeJS. Кстати, необязательно для этого запаковывать приложение каждый раз в контейнер — разрабатывайте локально.
