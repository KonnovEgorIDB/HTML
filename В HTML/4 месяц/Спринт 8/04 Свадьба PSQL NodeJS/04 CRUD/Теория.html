CRUD

С помощью ORM можно быстро написать классический CRUD любой сущности.

Кстати, CRUD — это всего лишь акроним, описывающий 4 базовые функции для работы с базой:

  1. C — Create,
  2. R — Read,
  3. U — Update,
  4. D — Delete.

Create

Создание строки работает через метод create:

await User.create({
  name: 'User 1',
});

Обратите внимание, вам нужно всего лишь импортировать вашу модель для вызова методов.

import User from './models/User';

// User.create();
// User.findOne();
// ...

Если вам нужно множественное (bulk) создание сразу нескольких строчек — можно использовать метод bulkCreate. Избегайте исполнения операций в цикле:

for (какое-то условие) { 
  User.create();
}

Это плохо тем, что вы вместо одного запроса на создание делаете N запросов. Это приводит к максимально неэффективному использованию базы данных, и ваши пользователи очень быстро начнут страдать от долгой загрузки данных.

Вместо этого в bulkCreate можно передать массив сущностей и будет выполнен один запрос INSERT в базу:

await User.bulkCreate([
	{
	  name: 'User 1',
	},
	{
	  name: 'User 2',
	}
]);

Кстати, вот тут пригодится дженерик класса Model — он принимает TModelAttributes и TCreationAttributes, которые позволяют TypeScript корректно понимать передаваемые в create или bulkCreate объекты и защищать вас от ошибок неверных типов (например, если в name передать число — должна быть ошибка типов).

Read

Операции чтения работают через методы find*.

Получить все строки можно через метод findAll:

const user = await User.findOne({
  where: {
    name: 'User 1'
  }
});
const {name} = user;

await User.findAll({
  where: {
    ownerId: 1
  },
  attributes: ['id', 'name']
});

Можно регулировать получаемые атрибуты. По умолчанию получаете всё:

const user = await User.findOne({
  where: {
    name: 'User 1'
  },
  attributes: ['id', ['name', 'other_field']]
});

Если нужно делать более сложные запросы, например, с оператором OR, можно использовать операторы из ORM Op:

import { Op } from 'sequelize';

const userModel = await User.findOne({
  where: {
    [Op.or]: [
      { name: { [Op.like]: 'А%' } },
      { saveDate: { [Op.gt]: '2018-04-09 13:25:13' } }
    ]
  }
});

Больше про операторы можно почитать в документации.

Поиск по id можно делать как через findOne:

await User.findOne({
  where: { id: 23 }
});

Так и через отдельный метод:

await User.findByPk(23);

Также можно работать и с count, offset, order, limit:

await User.findAll({
  order: [
    ['name', 'DESC']
  ],
  offset: 2,
  limit: 2
});

await User.count({
  where: {
    id: 1
  }
});

ORM позволяет делать все стандартные действия. В том числе и группировку:

await User.findAll({
  attributes: [
    'id',
    [
      Sequelize.fn('count', Sequelize.col('name')),
      'countNotes'
    ]
  ],
  group: ['id']
});

Интересно также то, что можно использовать метод, который выполняет создание объекта, если не нашёл его в базе:

const user = await User.findOrCreate({
  where: { name: 'User 1' },
  defaults: {
    name: 'User 1',
		...other_fields,
  }
});

Этот метод вряд ли будет применяться к сущности пользователей, но, например, к сущности заметок отлично может подойти.

Update

Обновление строк происходит через метод update:

await User.update(
  {
    field: 'some value'
  },
  {
    where: { id: 1 }
  }
);

ORM позволяет изменять сущности и через мутацию полученного объекта:

const user = await User.findOne({
  where: { id: 1 }
});
user.some_field = 'some value';
await user.save();

Delete

Удаление можно делать как через метод destroy, так и через вызов метода у инстанса найденной сущности:

await User.destroy({
  where: { id: 23 }
});

const user = await User.findOne({
  where: { id: 23 }
});
await user.destroy();
