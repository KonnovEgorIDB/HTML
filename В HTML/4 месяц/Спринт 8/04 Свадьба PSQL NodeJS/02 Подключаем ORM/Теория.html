Подключаем ORM

Когда проекты небольшие, две-три таблицы, — вполне достаточно работать с драйвером напрямую и не усложнять кодовую базу. Однако в больших проектах базы данных сложнее, больше зависимостей между таблицами и вообще начинается путаница — какая структура в базе данных и как она соответствует объектам в нашем коде (и соответствует ли).

Даже в маленьких проектах бывает неудобно переключаться с TypeScript на SQL и обратно.

Для борьбы с этой сложностью и для упрощения работы с базой из кода придумано несколько паттернов:

  • Шлюз таблицы данных (Table Data Gateway);
  • Шлюз записи данных (Row Data Gateway);
  • Активная запись (Active Record);
  • Преобразователь данных (Data Mapper);
  • Источник данных (Data Access Object).

Так или иначе все эти паттерны задействованы в концепции объектно-реляционного отображения.

ORM — Object-Relational Mapping

Это технология программирования, которая связывает базы данных с концепциями объектно-ориентированных языков. Проще говоря, вы можете описать привычные классы на вашем языке программирования, а ORM посмотрит на эти классы и сделает свою работу:

  • Создаст таблицы в базе данных (это умеет почти любая ORM).
  • Будет следить за тем, как вы меняете код классов, и сможет создавать миграции.
  • Обогатит классы своими методами, чтобы вы вообще забыли о таблицах.

ORM можно представить как прослойку между приложением и SQL-синтаксисом базы данных. Она позволяет описывать работу с базой в привычном ООП стиле.

ORM-сервисов очень много, но использовать в данном курсе будем один из самых популярных — Sequelize.

В этой теме вы по шагам познакомитесь с процессом работы с ORM. Дополнительный пример подключения и работы с Sequelize вы сможете найти в репозитории на GitHub.

Установим все зависимости, необходимые для работы с базой данных:

~$ npm install pg # Драйвер PostgreSQL
~$ npm install sequelize sequelize-typescript # Сама ORM (и типизация для неё)
~$ npm install reflect-metadata # Пакет для получения информации об объектах в рантайме

Для корректной работы в tsconfig.json надо включить следующие флаги:

"experimentalDecorators": true,
"emitDecoratorMetadata": true,

Подключаемся к базе данных

import { Sequelize, SequelizeOptions } from 'sequelize-typescript';

const sequelizeOptions: SequelizeOptions = {
  host: 'localhost',
  port: 5432,
  username: 'user',
  password: 'pass',
  database: 'dbname',
  dialect: 'postgres' // 'mysql', 'sqlite', 'mariadb', 'mssql'
};

const sequelize = new Sequelize(sequelizeOptions);

Подключение состоит из вызова конструктора ORM. Параметры подключения передаются в виде объекта. Всё, как можно заметить, типизировано. Познакомиться с примером подключения к базе вы можете в репозитории раздела.

Позаботьтесь о том, чтобы подключение к базе данных произошло до старта вашего WEB (в нашем случае Express) приложения. Как правило, приложения разрабатывают, полагаясь на то, что база уже подключена и к ней можно обращаться.

Указываете параметры вашей базы данных (пользователя, хост, порт) и какой драйвер используете. В нашем случае — это pg (PostgreSQL). Ура! Теперь можно начать работу с базой через ORM.
