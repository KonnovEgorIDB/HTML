Метрики

Обзор

Вы запустили сервис. Что дальше? Кроме новых фичей и проблем, найденных вами и вашими коллегами, стоит всё же задуматься о пользователях. Менеджеры продукта должны уметь наблюдать за действиями пользователей:

  • на каких страницах они бывают,
  • откуда попадают на сервис (соц. сети, поисковик),
  • куда кликают на сайте,
  • узнать, нажали ли кнопку оформить заказ, если не увидели нажатие на кнопку, оплатить,
  • и много-много других кейсов.

Всё это позволяют сделать сервисы, которые логируют действия пользователей. Таких сервисов очень много:

  • Google Analytics,
  • Yandex Metrika,
  • Facebook Pixel.

Даже Tiktok уже можно подключить к Facebook Pixel…

Необязательно останавливаться на одном, но стоит понимать, что эти сервисы работают через поллинг. Потому ваш сервис будет под дополнительной нагрузкой.

У Яндекс Метрики есть «киллер-фича» — это webvisor. Яндекс умеет строить карту кликов и перемещений пользователя по сайту. То есть вы можете смотреть не только на табличные результаты, куда пользователь нажимал, но и видеть, как долго он «медитировал» на экран или кнопку.

Кроме того, webvisor умеет показывать тепловую карту на видео. То есть можно наблюдать, как долго пользователь «возился» с формой регистрации или оформлением заявки, какое поле не мог заполнить дольше всего.

В React-приложениях удобно использовать такие библиотеки, как, например, react-yandex-metrika. Можете также написать свою обёртку сервиса.

Работает крайне просто:

  1. Добавляем компонент в Core-проекта (чтобы подгружался на всех страницах);
  2. Добавляем необходимые параметры (включаем webvisor, указываем номер счётчика);
  3. PROFIT!
import React, {FC} from 'react';
import {YMInitializer} from 'react-yandex-metrika';

import {ACCOUNTS, OPTIONS, VERSION} from './const';

const YaMetrika: FC = () => {
  return (
    <YMInitializer
      options={OPTIONS}
      accounts={ACCOUNTS}
      version={VERSION}
    />
  );
};

export default YaMetrika;

Настройки могут выглядеть примерно так:

export const OPTIONS = {
  webvisor: true,
};

export const VERSION: '1' | '2' = '2';
export const ACCOUNTS: number[] = (function () {
  switch (NODE_ENV) {
    case config.__PROD__:
      return [123];
    case config.__TEST__:
      return [312];
    default:
      return [];
  }
})();

Вот такой компонент полностью покрывает все ваши пожелания по Яндекс Метрике. Дальше нужно только «обвязывать» обработчики и события необходимыми целями из метрики.

Если хочется своё

Если вы не хотите использовать библиотеку, можно воспользоваться своими навыками по работе с DOM. Покажем на примере TikTok-аналитики, как сделать подобное своими руками:

import {FC, useEffect} from 'react';
import isServer from '__utils/isServerEnvCheker';
import {SDK_ID} from './const';

const TikTokAnalytics: FC = () => {
  useEffect(() => {
    if (!isServer) {
      const scriptEl = window.document.createElement('script');
      scriptEl.type = 'text/javascript';
      scriptEl.async = true;
      scriptEl.src = `https://analytics.tiktok.com/i18n/pixel/sdk.js?sdkid=${SDK_ID}`;
      const body = window.document.body;
      body.append(scriptEl);
    }
  }, []);
  return null;
};

export default TikTokAnalytics;

Основываясь на этом примере, можно вставить любое тело (включая код Яндекс Метрики) и сделать такой же компонент. После чего просто подключить его через JSX:

// Где-то в Core проекта
 
<div id="main">
  <Router>
  </Router>

  <YaMetrika/>
  <TikTokAnalytics/>
</div>
